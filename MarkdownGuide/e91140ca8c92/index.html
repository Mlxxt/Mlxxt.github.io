Markdown食用指北（一） | 基础语法与写作起步

发表于2025-12-12|MarkdownGuide
|总字数:2.9k|阅读时长:8分钟|浏览量:

Markdown 是一种使用纯文本编写结构化文档的轻量级标记语言。你不需要反复点击工具栏，只要在文字前后添加少量符号，就能表达标题、列表、引用、链接、图片和代码等结构。

本章面向第一次接触 Markdown 的读者。读完后，你应该能够独立创建一个 .md 文件，写出结构清楚、语法正确、即使不渲染也容易阅读的短文。

1. 开始之前：Markdown 到底是什么

Markdown 可以同时指两件事：

  • 一套使用符号表示文档结构的书写规则。
  • 按照这套规则写成的纯文本文件，扩展名通常是 .md 或 .markdown。

Markdown 文件本质上仍然是文本文件。即使没有专门的软件，也能用记事本打开；经过博客程序、代码托管平台或编辑器渲染后，它才会显示为带样式的网页。

1.2 Markdown 不是完全统一的

Markdown 有多种解析器和“方言”。标题、段落、列表、引用、链接、图片和代码块等核心语法通常都能通用；表格、任务列表、脚注、数学公式、提示框和流程图等功能则可能依赖具体平台。

因此，本系列会区分三种情况：

  • 核心语法：优先使用，跨平台兼容性最好。
  • 常见扩展：很多平台支持，但发布前应预览。
  • 平台专用语法：只有确认网站支持时才使用。

4.1 普通回车不一定产生换行

在许多 Markdown 解析器中，只按一次回车属于“软换行”，渲染后可能仍然显示在同一段中。

需要强制换行时，常见方式有两种：

  • 在上一行末尾添加两个空格后回车。
  • 使用 HTML 的 <br> 标签，但这会降低可移植性。

对于普通文章，优先使用空行分段；只有诗歌、地址等确实需要逐行显示的内容，才使用强制换行。

符号被意外渲染 Markdown 特殊字符触发了语法 使用反斜杠转义或代码格式

13. 本章小结

本章介绍了 Markdown 的核心入门语法：

  • 使用标题建立层级。
  • 使用空行分隔段落。
  • 使用强调语法突出重点。
  • 使用列表和引用组织内容。
  • 使用链接和图片连接外部资源。
  • 使用行内代码和代码块展示技术内容。
  • 使用转义处理特殊符号。

下一章将不再逐个介绍孤立语法，而是学习如何把段落、列表、引用和代码组合成更复杂但仍然稳定的文档结构。

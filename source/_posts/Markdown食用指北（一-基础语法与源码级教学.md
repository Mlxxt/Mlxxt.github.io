Markdown 是一种极其优雅的轻量级标记语言。它的核心目的只有一个：让你在写作时双手不离开键盘，就能完成排版。本文章适合基础入门/长时间不使用后快速回忆语法/记忆不好反复查阅。

## 标题

在 Markdown 中，标题是通过井号`#`来控制的。通过`#*n+空格`来决定此时输入的是n级标题。

**输入源码：**

```Plaintext
# 这是一级标题 (通常作为文章大标题)

## 这是二级标题 (章节标题)

### 这是三级标题 (子章节标题)

#### 这是四级标题

......

```

**渲染效果：**
由于真的渲染出来会影响本文章的目录，所以只能截了个效果图供参考，大家可以自己去试试看看效果：

## 文本修饰（文字加粗、斜体）

文本修饰主要依靠星号 `*` 或波浪号 `~`。

输入源码：

```Plaintext

**这段文字会被加粗**

*这段文字会变成斜体*

***这段文字既加粗又斜体***

~~这段文字会被划上删除线~~

```

**渲染效果：**

**这段文字会被加粗**

*这段文字会变成斜体*

***这段文字既加粗又斜体***

~~这段文字会被划上删除线~~

## 列表

### 无序列表

如果你想罗列一些没有先后顺序的要点，可以使用减号 `-`（推荐）、加号 `+` 或星号 `*`。

**输入源码：**

```Plaintext

- 我是无序一号 (注意减号后面有空格)

- 不是无序吗哪来的一号

- 上下也是排序

```

**渲染效果：**

- 我是无序一号 (注意减号后面有空格)
- 不是无序吗哪来的一号
- 上下也是排序

### 有序列表

数字加上英文的句号 `.`。

**输入源码：**

```Plaintext

1. 哈哈这下我真的是一号了 (注意句号后面有空格)

2. 好吧那我是二号

3. 可恶那我就是三号了

```

**渲染效果：**

1. 哈哈这下我真的是一号了 (注意句号后面有空格)
2. 好吧那我是二号
3. 可恶那我就是三号了

## 引用

当你想引用别人的一段话，或者特别标注一段说明时，使用大于号 `>`。

**输入源码：**

```Plaintext

> 任何苦难，都能把我打倒。

> ——弗朗茨·卡夫卡

```

**渲染效果：**

> 任何苦难，都能把我打倒。
> ——弗朗茨·卡夫卡

## 链接与图片

这两者的语法非常像，是 Markdown 中稍微复杂一点的地方，由中括号 `[]` 和小括号 `()` 组成。 图片仅仅比链接在最前面多了一个感叹号 `!`。

**输入源码:**

```Plaintext
这是一个链接：

[广告位招租喵](https://mlxxt.github.io/)


这是一张图片：

![阅读中](https://github.com/Mlxxt/Image_Storage/blob/main/post/MarkDown/post1/example_photo.jpg?raw=true)

```

**渲染效果：**

这是一个链接：
[广告位招租喵](https://mlxxt.github.io/)

这是一张图片：
![阅读中](https://github.com/Mlxxt/Image_Storage/blob/main/post/MarkDown/post1/example_photo.jpg?raw=true)

## 代码块

这是程序员和技术写作者最常用的功能，也是使用markdown写作最常用的技术模块。用来包裹代码的符号叫做反引号 (Backtick)——`` `。

⌨️ 这个符号到底在哪？

在你的键盘左上角，`Esc` 键的正下方，数字 `1` 键的左边。 请**务必切换到英文输入法**，直接按下那个键，就会打出 `` `。

### 行内代码 (单行、少量代码)

如果你只是想在句子中突出几个代码单词，用单个反引号包起来即可。

**输入源码：**

```Plaintext

绞劲脑汁打出一句 `print("Hello World")`，~~你不觉得很神圣吗~~ 。

```

**渲染效果：**

绞劲脑汁打出一句 `print("Hello World")`，~~你不觉得很神圣吗~~ 。

### 多行代码块 (大段代码)

如果你要展示一整段代码，需要使用三个反引号。并且，你可以在第一行的三个反引号后面，写上这门代码的语言名字（比如 python, c, java, javascript），这样渲染出来的代码就会有漂亮的彩色高亮！

**输入源码：**

````Plaintext
```c

#include <stdio.h>

int main() {

    printf("Hello, World!\n");
    return 0;
}
```
````


第一行是三个反引号加上字母 c，最后一行是独立的三个反引号，用来闭合代码块。

**渲染效果：**


```c
#include <stdio.h>


int main() {

    printf("Hello, World!\n");
    return 0;
}

```
